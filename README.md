# HangRail

干洗挂衣杆：按衣长一维 First-Fit 上杆，取件释放，逾期扫描。支持每根挂杆登记一段半开区间作为**快递专区**，仅供快递加急工单占用。

## 快递专区规则

- 专区为半开区间 `[起, 止)`（厘米），起止非法（负、空区间）或越过杆长拒绝保存。
- 普通工单上杆：First-Fit 将专区视为占用，**跳过专区内部空隙**，即使专区空着也不挂普通衣。
- 加急工单上杆：先在本杆专区内找最左空隙；专区放不下时再按现网规则扫专区外空隙；仍可落到同店其它杆（先各杆专区、再全杆）。
- 未划专区的挂杆保持全杆可挂。
- 种子数据：B 杆前 `[0, 60)` cm 为专区，普通羽绒服跳过该段，加急短衣可挂入。

## 页面

- `/stores` — 门店
- `/rails` — 挂杆
- `/orders` — 工单
- `/occupancy` — 占位图
- `/pickup` — 取件
- `/overdue` — 逾期

## 使用说明

1. 查看门店挂杆长度；挂杆页可维护每根杆的快递专区起止（厘米），非法区间会被拒绝。
2. 工单页可将工单标记为“快递加急”；加急工单优先上专区，普通工单自动跳过专区空隙。
3. 工单上杆按衣长 First-Fit 占位。
4. 占位图为横向尺线，专区以斜纹虚线段区分、加急占位高亮；取件释放；逾期页扫描清退。
